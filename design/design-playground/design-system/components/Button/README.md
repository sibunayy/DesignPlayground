Buttons carry one action each: a primary fill in the mode accent and a quiet secondary.

- Primary: `accent` fill, `on-accent` text, `button` style, `radius-md`, 56px high. Use one per view.
- Secondary: `button-2` fill, `ink` text. Use it for Previous and other back steps.
- Disabled: 40% opacity and a not-allowed cursor. Name the reason in nearby text.
- Label says what happens: "Check spacing", "Next pair", "Start over".
- Hover raises brightness. Press scales to 0.98 in 80ms. Reduced motion removes both.
- Focus ring: 3px `ink` outline with a 2px offset.
