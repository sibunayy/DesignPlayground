Icon toggles switch assist features on and off: answer zone, guides and ruler, squint blur and grid.

- Hit area is 44px (`tap-target`). The visible chip is 32px with `radius-sm`.
- Off: `chip` fill, `ink` icon. On: `accent` fill, `on-accent` icon.
- Each button sets `aria-pressed` and an `aria-label`. The icon is `aria-hidden`.
- Icons: 18px, 24 viewBox, 2px stroke, round caps, `currentColor`.
- Place the row at the top centre of the stage. Defaults: grid on, the rest off.
